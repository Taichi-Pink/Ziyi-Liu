Generalize and Guide: Decomposing Rewards for
Few-Shot Inverse Reinforcement Learning

MPG learns a generalizable and informative reward by combining multi-task demonstrations with policy proximity. A multi-task discriminator transfers shared structure across related tasks, while a proximity function provides corrective guidance when the agent deviates from expert behavior.

Abstract

Inverse reinforcement learning (IRL) provides a powerful framework for learning from demonstrations. However, real-world tasks often exhibit substantial natural variations (e.g., picking up mugs with varying shapes), making it impractical to collect demonstrations that fully specify a new task under every possible scenario. In practice, while demonstrations for the target task are limited, it is often easier to obtain datasets of heterogeneous but related behaviors. This motivates the problem of few-shot IRL with multi-task demonstrations (FM-IRL), where an agent must learn a new task with substantial variations from only a limited number of target-task demonstrations, together with sufficient demonstrations of related tasks and online agent experience.

We introduce Multitask discriminator Proximity-Guided IRL (MPG), which learns two complementary reward components: (1) a generalizable discriminator that transfers shared structure across related tasks to identify expert behavior in a new task, and (2) a proximity function that measures how far a state deviates from expert behavior and provides corrective guidance during exploration. We demonstrate the effectiveness of our method on multiple challenging navigation and manipulation tasks under significant variations (e.g., object configurations, table layouts, and initial robot poses), resulting in an average 35.4% increase in success rate over the next best method.

Problem Setting: FM-IRL

FM-IRL reflects a practical robotics scenario: multi-task expert demonstrations are often available, but interaction with multi-task training environments is difficult to obtain. The agent must learn a new target task using:

  • A small set of target-task demonstrations
  • A larger multi-task demonstration dataset from related tasks
  • Online interaction with the target-task environment only

Unlike meta-IRL, FM-IRL does not require access to multi-task environments. Unlike standard IL, MPG learns a reward function that supports online policy optimization and recovery from unseen states.

Method: MPG

MPG decomposes the learned reward into two synergistic components:

Multi-Task Discriminator

A demonstration-conditioned discriminator predicts whether a state-action pair is expert for a given task. Trained on both target and multi-task demonstrations, it transfers shared structure across tasks to recognize expert behavior under diverse intra-task variations.

Proximity Function

A proximity function estimates temporal distance to the expert state distribution, providing dense corrective guidance in non-expert regions. It is trained with temporal consistency constraints inspired by quasimetric learning.

R̃(st, at, st+1) = d(st, at) + λ [p(st) − p(st+1)]

The combined reward encourages expert-consistent behavior while guiding the agent back toward the expert distribution when it deviates. The policy is optimized with standard RL (PPO) using this decomposed reward.

Experiments

We evaluate MPG on navigation and manipulation tasks with substantial intra-task variation:

  • Maze2D (D4RL): navigate to a goal among fixed objects with varying start positions
  • Block Stacking: pick and place colored blocks with random initial configurations
  • FactorWorld: robot manipulation with varying object, table, and arm configurations

MPG consistently outperforms IL, IRL, meta-IRL, and discriminator-only baselines including BC, SQIL, GAIL, MT-AIRL, PEMIRL, GoalPro, and DVD. Both reward components contribute: ablations show that the discriminator alone and proximity alone underperform the full method, and removing multi-task data significantly degrades performance.
